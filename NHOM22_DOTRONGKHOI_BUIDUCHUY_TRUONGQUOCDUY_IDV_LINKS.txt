3. HƯỚNG DẪN KHỞI CHẠY DASHBOARD CỤC BỘ (LOCAL SETUP)
--------------------------------------------------------------------------------
Bước 1: Cài đặt các thư viện cần thiết
$ pip install -r requirements.txt

Bước 2: Chạy Pipeline ETL kết nối 4 bảng quan hệ và làm sạch dữ liệu
$ py src/data_pipeline.py

Bước 3: Sinh 10 biểu đồ tĩnh EDA (Matplotlib/Seaborn)
$ py src/eda_analysis.py

Bước 4: Huấn luyện mô hình Hồi quy Logistic (Scikit-Learn)
$ py src/model_training.py

Bước 5: Khởi chạy Bảng điều khiển tương tác Streamlit
$ streamlit run src/app.py
(Truy cập trên trình duyệt web tại địa chỉ: http://localhost:8501)
